# Data-Science
📘 Data Science University Assignment

A collection of data science assignments completed as part of university coursework, focusing on practical implementation of data analysis, visualization, and machine learning fundamentals using Python.

🚀 Overview

This repository contains structured academic assignments that demonstrate core concepts in data science, including:

Data cleaning and preprocessing
Exploratory Data Analysis (EDA)
Data visualization
Statistical reasoning
Basic machine learning workflows

Each assignment is implemented using real datasets and Python-based data science tools.

🧰 Tech Stack
Python 🐍
Jupyter Notebook 📓
Pandas
NumPy
Matplotlib
Seaborn
